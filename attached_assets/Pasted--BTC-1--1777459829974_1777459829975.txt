Скальпинг-бот для BTC с высоким плечом
Давай разберём архитектуру по слоям.

1. Источники данных
Биржи с нужными инструментами

Binance Futures / Bybit / OKX — ликвидность, стаканы, фандинг
Deribit — опционный поток (умные деньги)
Bitfinex — исторически информативный стакан

Стаканы и объёмы (Order Flow)

WebSocket потоки: depth (стакан), aggTrade (сделки), markPrice
Footprint / кластеры: нужен кастомный агрегатор тиков по ценовым уровням
Imbalance: дисбаланс bid/ask в стакане → сигнал давления
Large orders / icebergs: фильтрация крупных заявок (>X BTC) — часто маркеры институционального входа
CVD (Cumulative Volume Delta): разница между buy/sell объёмом → тренд агрессии

Биржевые данные 2-го уровня

Open Interest (OI) — рост OI + цена вверх = сильный тренд; рост OI + цена вниз = шорт-давление
Funding Rate — экстремальные значения = разворот (выжигание толпы)
Liquidations — каскадные ликвидации = momentum-сигнал или ловушка
Long/Short Ratio — contra-indicator при экстремумах


2. Технический анализ
Поддержка / Сопротивление
Источники уровней:
├── POC (Point of Control) из Volume Profile — самый честный уровень
├── HVN/LVN (High/Low Volume Nodes) — зоны притяжения/отталкивания
├── Round numbers (круглые цены: 100k, 95k, 90k...)
├── Предыдущие дневные/недельные High/Low
└── Liquidation clusters (по данным Coinglass/Hyblock)
Индикаторы для скальпинга

VWAP + отклонения (σ1, σ2) — ключевой якорь дня
EMA 9/21 на 1m/3m — быстрая тенденция
RSI с дивергенцией на тиковом/1m графике
Bollinger Bands — сжатие = готовится движение
ATR — для динамического стоп-лосса

5. Risk Management (критично при высоком плече)

Kelly Criterion или фиксированный % риска (0.5–1% депозита на сделку)
Max drawdown circuit breaker — если потери >3% за день → бот останавливается
Плечо адаптивное — зависит от ATR и волатильности (высокий ATR → меньше плечо)
Cooldown после серии убытков — обязательно
SL всегда в рынке — никогда не торговать без стопа на плече


6. Технический стек
Python:
├── ccxt / ccxt.pro  — унифицированный доступ к биржам (WebSocket included)
├── pandas / numpy   — обработка данных
├── ta / pandas-ta   — индикаторы
├── asyncio          — асинхронность (обязательно для скальпинга)
├── Redis            — быстрый кеш для стакана/тиков
├── PostgreSQL/TimescaleDB — хранение истории
└── Telegram Bot API — уведомления и ручной контроль

Инфраструктура:
├── VPS близко к бирже (Токио/Сингапур для Bybit/Binance)
├── Latency < 10ms — критично для скальпинга
└── Replit — только для разработки, НЕ для прода
