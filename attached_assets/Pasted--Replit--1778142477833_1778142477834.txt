Детальное Техническое Задание для Replit Бота: Интеграция Фрактального Паттерн-Мэтчинга и Подтверждения Объемами

1. Введение

Это техническое задание (ТЗ) предназначено для выполнения конкретных изменений в коде вашего BTC скальпинг-бота. Цель — сделать фрактальный паттерн-мэтчинг основным фильтром для торговых сигналов, подтверждаемым анализом объемов, кластеров и стакана. Следуйте инструкциям пошагово и точно, чтобы избежать ошибок.

2. Общие Инструкции для Replit Бота

•
Точность: Внимательно читайте и следуйте инструкциям. Обращайте внимание на номера строк и точное содержимое для замены.

•
Резервное копирование: Перед внесением любых изменений, сделайте резервную копию всех файлов, которые будут модифицированы.

•
Пути к файлам: Все пути к файлам указаны относительно корневой директории проекта artifacts/api-server/src/.

6. Заключение

После выполнения этих изменений ваш бот будет работать по следующей логике:

1.
fractalService будет постоянно искать фрактальные паттерны и генерировать FractalSignal.

2.
signal.ts будет использовать этот FractalSignal как первичный гейт. Только если фрактальный паттерн найден и достаточно силен, signal.ts продолжит проверять остальные гейты (CVD, стакан, кластеры ликвидаций, фандинг).

3.
botEngine.ts будет открывать позиции только тогда, когда signal.allGatesPassed (который теперь включает фрактальный гейт) истинен, и, опционально, если overall_signal_score фрактала достаточно высок.

4.
signalTracker.ts будет уведомлять о сигналах, которые прошли все эти гейты.

Это значительно повысит качество и релевантность торговых сигналов, а также уменьшит их частоту, соответствуя вашей стратегии "паттерн -> объемы -> вход".
