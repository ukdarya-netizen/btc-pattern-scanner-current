1. Внедрение Дебаг-Логирования Причин Отклонения Сигналов в Telegram (src/services/signal.ts)

Цель: Бот должен отправлять в Telegram сообщение каждый раз, когда потенциальный сигнал отклоняется одним из гейтов, с указанием точной причины.

Инструкции:

Откройте файл src/services/signal.ts.

Найдите функцию compute(): SignalResult (начинается примерно со строки 581).

Внутри этой функции, для каждого блока if (!gate.pass) (их несколько), добавьте вызов telegramService.notifyChannel.

Пример для фрактального гейта (Gate 0):

Найдите блок, который выглядит примерно так (строки 600-602):

TypeScript

ЗАМЕНИТЕ ЕГО НА:

TypeScript


    // Gate 0: Fractal Pattern
    const fractalGate = fractalService.gateCheck(engineDirection);
    if (!fractalGate.pass) {
      const debugMsg = `[DEBUG] 🚫 ${engineDirection.toUpperCase()} сигнал отклонен: Фрактальный гейт. Причина: ${fractalGate.reason} (Score: ${fractalGate.score.toFixed(2)})`;
      logger.debug({ reason: fractalGate.reason }, debugMsg);
