Техническое Задание: СТРАТЕГИЯ "SMART MONEY" (БЕЗ ШУМА)

Дата: 14 мая 2026
Цель: Полная зачистка кода от фракталов и минутного шума. Бот должен работать только на подтвержденных объемах, крупных кластерах и реальном дисбалансе стакана.




1. Файл src/services/signal.ts (Радикальная чистка)

1.1. Удаление Фрактального Гейта (Gate 0):
ПОЛНОСТЬЮ УДАЛИТЬ блок кода Gate 0 (примерно строки 600-605). Бот больше не тратит ресурсы на поиск паттернов.

1.2. Новая иерархия гейтов в compute():
Перестройте функцию так, чтобы проверка шла в следующем порядке:

1.
CVD (5m/15m) — Подтверждение рыночного давления.

2.
Order Book Imbalance — Проверка "плит" в стакане.

3.
Whale Activity — Поиск крупных принтов.

4.
Liquidation Clusters — Поиск цели (топлива).




2. Файл src/services/cvdService.ts (Убийца минутного шума)

2.1. Фильтрация таймфреймов:
Измените логику gateCheck так, чтобы она ИГНОРИРОВАЛА 1-минутную дельту.

•
Условие прохода: Дельта на 5м и 15м должна быть в одном направлении.

•
Порог: CVD_SCORE_THRESHOLD = 0.85.

•
Логика: Если 5м дельта растет, а 15м падает — сигнал ОТКЛОНЯЕТСЯ.




3. Файл src/services/liquidationService.ts (Охота за крупной рыбой)

3.1. Повышение планки:

•
MIN_SL_CLUSTER_USD = 10_000_000 (Ищем только скопления от $10 млн).

•
MIN_TP_CLUSTER_USD = 7_000_000.

•
Логика: Если впереди нет крупной пачки стопов, входить нет смысла — нет "топлива" для движения в 2%.




4. Новые модули (Создать с нуля)

4.1. src/services/orderbookService.ts (Стакан):
Реализовать функцию checkImbalance.

•
Метод: Считать суммарный объем лимитных заявок в диапазоне 0.5% от текущей цены.

•
Фильтр: Если объем заявок против движения (сопротивление) в 2.5 раза больше, чем по движению (поддержка) — ОТКЛОНЯТЬ.

4.2. src/services/whaleTrackerService.ts (Крупные принты):
Реализовать функцию checkWhaleActivity.

•
Метод: Сканировать ленту сделок (Trades) за последние 3 минуты.

•
Фильтр: Сигнал проходит только если зафиксирован хотя бы один рыночный ордер > $1,500_000 в направлении сигнала. Нет кита — нет сделки.
